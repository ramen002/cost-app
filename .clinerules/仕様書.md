# 原価計算アプリ（メニュー開発アプリ）

## 1. 概要

- **目的**: 料理・パンなどのメニュー開発時に、材料の仕入れ価格・使用量から原価・利益を計算し、効率的にメニュー開発を行う。
- **ターゲット**: 個人や小規模店舗の料理人・開発者
- **プラットフォーム**: Expo（iOS / Android / Web対応）
- **データ保存**: ローカルストレージ（AsyncStorage）
- **将来的対応**: SQLite / Firestore / Supabase等への移行可能
- **UI設計**: NativeWind + モーダルベースUI + シンプル & モダン
- **広告**: バナー広告表示（課金で非表示切替可能）
- **更新コンテンツ**: WebViewによる操作マニュアル・Tips・FAQ配信

---

## 2. 主要画面構成

※の画面はフッターとする

| 画面 | 機能概要 |
| --- | --- |
| ホーム※ | 最近計算したレシピ（履歴）、「材料追加」ボタン（モーダル表示）、「レシピ追加」ボタン（モーダル表示） |
| 材料一覧※ | 材料マスタ登録・編集・削除・複製。単位（プリセット or カスタム）、仕入れ価格、カテゴリなど |
| レシピ一覧※ | レシピ登録・編集・削除・複製。材料選択、分量入力、計算結果表示。レシピのスケール変更可能 |
| 原価計算※ | 材料・分量を入力して原価計算。1人分・1個あたりの単価表示。原価率計算もオプションで表示→そのままレシピに登録可能 |
| 原価計算（レシピ詳細から遷移） | 登録済みレシピの原価計算。材料・分量の置き換えした場合の利益率など、柔軟に計算可能 |
| 材料追加（モーダルUI） | プリセット単位（g, ml, 個, 袋など）＋カスタム入力対応 |
| レシピ追加（モーダルUI） | 材料選択、分量入力、メモなど |
| 計算履歴一覧（最新10件を保持） | 過去の計算結果を一覧表示、再計算やコピーが可能 |
| ヘルプ（WebView） | 操作マニュアル・Tips・FAQをWebViewで表示。外部更新が容易 |
| 設定画面 | 広告表示ON/OFF、通貨単位設定、バックアップ/復元（JSON出力） |

## 3. 機能詳細

### 3.1 材料管理

- 新規材料登録: 材料名、単位（プリセット＋カスタム入力）、仕入れ価格、在庫数、カテゴリ
- 編集・削除・複製
- 材料検索・フィルタ

### 3.2 レシピ管理

- レシピ名、材料選択、分量入力
- 計算ボタンで原価算出
- 複製・コピー・削除機能
- スケール変更（1人分 / n個分 / バッチ単位）
- 検索

### 3.3 原価計算

\[通常]

- 総原価計算: 材料 × 分量の合計
- 単価換算: 1人分 / 1個あたり
- 販売価格入力で利益額・利益率・原価率自動計算
- 材料別コスト可視化: 棒グラフ・円グラフ
→ 円グラフは **上位5位＋その他** 形式で集約
- モーダルで材料選択やスケール変更可能
- 広告表示: バナー広告（課金で非表示）

\[登録済みレシピの計算]

- 複製→編集→再計算が可能
- 置き換えた材料・分量で再度利益率を算出

### 3.4 計算履歴

- 日付順に表示
- 再計算・コピー可能

### 3.5 WebViewマニュアル

- 操作マニュアル・Tips・FAQを外部HTMLで提供
- 更新頻度の高いコンテンツを即時反映可能
- 広告バナーを下部に配置可能

### 3.6 広告 & 課金

- 広告表示ON/OFF
- Zustand store で状態管理

## 5. 状態管理

- **Zustand** を採用
- 全画面対応: 材料・レシピ・計算・履歴・設定
- モーダルの開閉状態もZustandで管理
- 利点: `router.back()` で戻ったときもリストや計算内容が即更新可能

---

## 6. UI / UX ポイント

- **NativeWind** による統一スタイリング
- **共通ヘッダー**: タイトル・戻るボタン・アクションボタン
- **モーダルUI**: 材料追加・レシピ追加・スケール変更・共通メッセージ
- **グラフ表示**: 棒グラフ（材料別原価）・円グラフ（上位5位＋その他）
- **広告表示**: 広告非表示は課金で切替可能
- **スクロール・フォーム最適化**: 数値入力専用キーボード対応
- カラー使い方（仕様カラーは下部のカラー設定を参照する）
    - ナチュラルで温かみのあるベース
    - アクセントでメリハリあり
    - 淡色パレットは円グラフ・フォルダ色分けに最適
    - 強調オレンジは使いすぎないように注意（メリハリは重要）

## 8. 実装方法ポイント

1. **プロジェクト作成**

```bash
npx create-expo-app@latest expo-app --template blank-typescript

```

1. **ライブラリ追加**

```bash
npm install nativewind zustand victory-native react-native-svg react-native-google-mobile-ads react-native-webview

```

1. **Expo Router ディレクトリ構成**を採用
- `app/_layout.tsx` で Tab Navigator
- `app/(modals)/` 配下でモーダルコンポーネント
1. **Zustand store**
- `IngredientsStore.ts`, `recipesStore.ts`, `calculatorStore.ts`, `historyStore.ts`, `settingsStore.ts` に画面横断の状態管理
1. **モーダル対応**
- 共通Modalラッパーで、材料選択・スケール変更を画面どこでも開閉可能
1. **広告・課金対応**
- `settingsStore.adsEnabled` で表示切替
- `settingsStore.unlockPremium()` で課金反映
1. **計算・グラフ表示**
- 原価・販売価格・利益・利益率・原価率計算
- `CostPieChart.tsx`、`CostBarChart.tsx` で可視化
